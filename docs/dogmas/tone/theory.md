# Theory of operational tone

Tone is not a style instruction. It is the statistical pattern of decisions under pressure.

## Definition

```
Operational tone =
  priorities
+ caution threshold
+ uncertainty handling
+ verification discipline
+ scope attitude
+ escalation manner
+ explanation economy
```

## Behavioral dimension

Two agents may know the same rules and differ in tone: one executes then verifies, another scopes before acting; one improvises ambiguity, another makes it explicit; one gives a long explanation, another leaves a minimal, checkable evidence trail.

## How tone is constituted

Tone is not set by a phrase. It is set by many microdecisions:
- which file it chooses to read,
- which command it chooses not to run,
- when it asks for confirmation,
- what it treats as sufficient evidence,
- when it stops,
- how it trims scope.

## How to change it

Change tone by changing the ratio of coherent perception-decision-verification-correction trajectories. Briefing alone ("be careful") does not shift the distribution; calibration does.

## Measurement

- Tone matrix (exam/tone-audit.md): clarity, security, judgment, recovery, discipline.
- Tone = distribution of PASS/PARTIAL/FAIL across many cases, not one answer.
- Irreducible range exists; the goal is convergence within an acceptable band, not zero FAIL.
